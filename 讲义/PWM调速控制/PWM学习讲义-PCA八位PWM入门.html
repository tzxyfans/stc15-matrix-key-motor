2PWM 到底是什么？为什么用它调速

PWM 是 Pulse Width Modulation（脉冲宽度调制）的缩写。名字很吓人，本质却极其朴素：在一个固定周期里，控制"通电"时间占多大比例。

（一）占空比：一开一关里的"时间账"

假设我们让一个引脚周期性地输出方波：高电平一段时间、低电平一段时间。一个完整周期里，高电平（或有效电平）所占的时间比例，就叫占空比（Duty）。例如周期 10 ms、高电平 5 ms，占空比就是 50%。

（二）为什么 PWM 能调电机转速？

直流电机是个惯性很大的负载：你通一下电、断一下电，它不会瞬间启停，而是"平均"地感受这段时间里的平均电压。占空比越大 → 平均电压越高 → 转速越快；占空比越小 → 平均电压越低 → 转速越慢。这就是"无级调速"的核心思路。

（三）PWM 调速 vs 模拟调压

❌ 模拟调压（电阻 / DA）

用可变电阻或 DA 输出连续电压。缺点是：调速元件（如电位器、三极管）上要消耗大量功率，发热严重、效率低；连续电压也难以被单片机精确控制。

✅ 数字 PWM 调速

引脚只在"全通（驱动）"和"全断（不驱动）"两个状态间切换，驱动管工作在开关状态，自身几乎不发热；占空比由数字量精确给定，效率高、可控性强。这正是电机调速的主流方案。

💡 一句话理解：PWM 不是"把电压变小"，而是"把电断断续续地给"。电机因为惯性，把这种断续"滤波"成了不同的平均转速。占空比 50% ≠ 电压减半那么简单，但它确实对应一个稳定的中间转速。

3STC15 用什么产生 PWM？—— PCA 模块1

思路清楚了：我们需要一路"周期固定、占空比可调"的方波。STC15 上没有专门的"PWM 外设"叫法，但它内置的 PCA（可编程计数器阵列） 就能干这件事，而且还是纯硬件自动输出。

（一）PCA 是什么

PCA 是 STC15 内部一个"多面手"定时器阵列，包含若干比较/捕获模块（本芯片有模块0/1/2）。其中模块1 的引脚 CCP1 固定映射到 P1.0，可以配置成 8 位 PWM 模式——一旦配置好，硬件就自动在 P1.0 上吐方波，完全不需要软件在中断里翻转引脚。

（二）为什么用 PCA，而不是"软件延时模拟"？

初学者常想到的办法是：用 while 循环 + DelayMs 高低电平交替，手工拼出 PWM。这在原理上没错，但有两个致命问题：① 占空比一变，CPU 就被"占住"，没法同时干别的事（比如刷 OLED）；② 用软件延时拼出来的频率很低、精度差，电机容易"哒哒"响。PCA 把这件事交给硬件，CPU 腾出手来，频率还精确——这正是工程上该用的方案。

💡 本讲范围：我们只用 PCA 的"8 位 PWM"这一种工作模式。PCA 还能做定时器、捕获测脉宽、外部中断等，那些是后话。先把"硬件出方波"这件事吃透。

4PCA 八位 PWM 的工作原理（重点）

这一节是全文的"心脏"。把下面三句话记住，PWM 就再也不是黑箱了。

（一）CL：一个不停累加的 8 位计数器

PCA 内部有一个 8 位计数器 CL，每个 PCA 时钟节拍加 1，从 0 一直数到 255，再回到 0，如此往复。一个完整的 0→255 循环就是 PWM 的一个周期，总共固定 256 拍。正因为"周期固定 256 拍"，所以 8 位 PWM 的频率只由时钟决定，与占空比无关。

（二）CCAP1L：决定"翻转点"的比较值

模块1 有一个比较寄存器 CCAP1L。硬件每一拍都把 CL 和它比一下，并按如下规则控制 P1.0：

  • 当 CL < CCAP1L 时，P1.0 输出低电平 = 驱动有效；
  • 当 CL >= CCAP1L 时，P1.0 输出高电平 = 不驱动。

因此，低电平（驱动）占空比 = CCAP1L / 256。例如想要 50% 占空比：CCAP1L = 128（128/256 = 50%）；想要停止驱动：CCAP1L = 0（CL 永远 ≥ 0，引脚恒高 = 一直不驱动）。

（三）CCAP1H 与 EBS：稳定与位数

  • EBS[1:0] = 00（在 PCA_PWM1 寄存器）：选定"8 位 PWM"模式。模式定了，周期就固定成 256 拍。
  • CCAP1H 是溢出重装值：当 CL 从 255 溢出回 0 时，硬件会用 CCAP1H 重新装载 CCAP1L。把 CCAP1H 和 CCAP1L 写成同一个值，占空比才不会因为重装瞬间而抖动。

💡 为什么低电平才是"驱动"？ 这是本程序的设计约定，也与 STC15 的 8 位 PWM 极性（EPC 位为 0 时）一致：比较器在 CL < CCAP1L 一侧输出低电平作为有效驱动，CCAP1L=0 时恒高即"断电"。配合电机驱动芯片，这个极性就能直接控速。重点是"比较值决定翻转点、低电平段=占空比"这个机制本身。

5关键寄存器配置（对照 motor.c 逐行讲）

原理清楚了，现在看 motor.c 里的 PWM_HW_Init() 是怎么把上面那一套"翻译"成寄存器赋值的。我们一个寄存器一个寄存器过。

（一）CMOD：时钟源与中断允许

CMOD（地址 0xD9）决定 PCA 用什么时钟、要不要溢出中断。它的位定义（务必对照手册 SFR 表，不要凭想象）如下：

本程序写 CMOD = 0x02：CPS[2:0] = 001，对应"系统时钟 / 2"（SYSclk/2），既拿到足够高的 PWM 频率（避开电机可闻啸叫），又不需要溢出中断。CPS 的编码表（同样查手册）：

CPS2 CPS1 CPS0PCA 时钟源本芯片对应频率
000系统时钟 / 1211.0592M ÷ 12 = 921.6 kHz
001（本程序采用）系统时钟 / 211.0592M ÷ 2 = 5.5296 MHz
100系统时钟（不分频）11.0592 MHz

⚠️ 对照手册验值（重要！）

源码里 CMOD = 0x02，即 CPS[2:0] = 001（B3~B1 三位），对应系统时钟 / 2；于是 fPCA = 5.5296 MHz，fPWM = 5.5296M ÷ 256 ≈ 21.6 kHz。这与源码注释、OLED 上显示的"21.6KHz"完全一致——数值是自洽的。

初学者最容易踩的坑：STC15 的 CPS 位于 B3~B1、ECF 位于 B0（不是 Philips 经典 80C51 PCA 里的 B6~B4 / B3）。写寄存器前务必对照手册 SFR 表确认位位置：若误把 0x02 写成 0x01（只置 ECF、CPS=000→SYSclk/12），频率就会悄悄变成约 3.6 kHz，注释和显示全都对不上。

（二）CCAPM1 / PCA_PWM1 / CCAP1L(H) / CCON

/* motor.c —— PWM_HW_Init() 节选（已按真实行为加注释）*/
static void PWM_HW_Init(void)
{
    /* P1.0 配推挽输出：PWM 引脚需要强驱动，准双向口边沿太慢会让电机异响 */
    P1M1 &= ~0x01;
    P1M0 |=  0x01;

    CCON     = 0x00;          /* 清 PCA 控制寄存器，干净启动 */
    CMOD     = 0x02;          /* CPS=001→SYSclk/2，8位PWM频率≈21.6KHz */
    PCA_PWM1 = 0x00;          /* EBS[1:0]=00 → 8 位 PWM */
    CCAPM1   = 0x42;          /* ECOM(位6)+PWM(位1) → 纯硬件输出 */

    CCAP1H = 0;
    CCAP1L = 0;             /* 占空比初值 0 = 不驱动 */

    CR = 1;               /* CCON.CR=1 启动 PCA 计数器（此时占空比0%）*/
}
  • PCA_PWM1 = 0x00：把 EBS 两位清 0，锁定 8 位 PWM。
  • CCAPM1 = 0x42：二进制 0100 0010，即 ECOM=1（比较功能使能）+ PWM=1（PWM 模式），其余位 0 → 纯硬件输出、不产生中断。
  • CCAP1H = CCAP1L = 0：初值占空比 0，电机先不转，等 Motor_Forward 来启动。
  • CR = 1：置 CCON 的 CR 位，PCA 计数器才开始跑。

💡 P1.0 为什么配推挽？ PWM 是高频方波，若用默认的准双向口，引脚上升/下降沿很"肉"，方波边沿发钝，电机容易啸叫甚至发热。推挽输出（M1=0, M0=1）能提供强上拉/强下拉，边沿干净。这是驱动类引脚的通用讲究。

6电机模块封装与 main 的设计思路

底层寄存器都藏在 motor.c 里了。站在 main.c 的角度，我们只需把电机当成一个"黑盒"，调用几个清晰的函数即可。这正是模块化的价值。

（一）motor.h 对外接口

函数作用
Motor_Init()初始化 PCA PWM + 端口，默认惯性停转（安全状态）
Motor_Forward()正转：松闸 → 方向正 → 启动 PWM 方波（按当前占空比）
Motor_Reverse()反转：松闸 → 方向反 → 启动 PWM 方波
Motor_Coast()惯性停转：停 PWM 驱动、不刹车，靠惯性与阻尼自由减速
Motor_Brake()刹车停转：先停 PWM → 再拉低 BRAKE 短接电机两端
Motor_SetSpeed(duty)设占空比 0~100（运行中改，立即生效）
Motor_GetSpeed()读取当前占空比

（二）Motor_Forward：顺序不能乱

void Motor_Forward(void)
{
    BRAKE = 1;            /* 1. 先松闸，否则刹车会强制锁死电机 */
    DIR   = 1;            /* 2. 设置正转方向 */
    PWM_Start();          /* 3. 启动 PWM 方波，按当前占空比驱动 */
}

三步顺序是有讲究的：必须先松闸再给方向、再启动 PWM。若先启动 PWM 而刹车还锁着，电机根本转不动，还可能瞬间拉高电流。

（三）Motor_SetSpeed：限幅 + 运行中实时更新

void Motor_SetSpeed(unsigned char duty)
{
    if (duty > 100) duty = 100;   /* 限幅 0~100 */
    s_duty = duty;                  /* 缓存新占空比 */
    if (CCAP1L != 0)            /* 若正在运行，立即改比较值，实时生效 */
    {
        unsigned char val = (unsigned char)(s_duty * 256 / 100);
        CCAP1H = val; CCAP1L = val;
    }
}

注意第 6 行的判断：如果电机当前是停着的（CCAP1L==0），只更新缓存 s_duty，等下次 Forward/Reverse 启动时才生效——这样就不会出现"明明停着却偷偷给占空比"的矛盾状态。

（四）main：三层调用链，主循环空转

void main(void)
{
    Motor_Init();          /* 初始化 PCA PWM + 端口，默认惯性停转 */
    Motor_SetSpeed(50);     /* 设占空比 50% */
    Motor_Forward();       /* 正转启动：松闸→方向正→PWM 方波 */

    OLED_Init(); OLED_Clear();
    OLED_ShowString(36, 0, "PWM");
    OLED_ShowChinese(60, 0, "调速");
    OLED_ShowChinese(0, 16, "频率");
    OLED_ShowString(32, 16, ":21.6KHz");
    OLED_ShowChinese(0, 32, "占空比");
    OLED_ShowString(48, 32, ":50%");
    OLED_ShowString(36, 48, "RUNNING");
    OLED_Update();

    while (1) { }          /* 主循环空转：PWM 由硬件自动跑，无需干预 */
}

💡 设计思想一句话：硬件干重复的活（出方波），软件只发"指令"（设占空比、启停、方向）。这种"配置一次、硬件自治"的分层思路，是后续做多任务、加按键、上中断的共同地基。

7频率与占空比计算 + 本章小结

把公式摆出来，以后不论换什么时钟、想要什么频率，你都能自己算。

（一）两个核心公式

指标公式本程序数值
PCA 时钟fPCA = 系统时钟 ÷ 分频11.0592M ÷ 2 = 5.5296 MHz
PWM 频率fPWM = fPCA ÷ 2565.5296M ÷ 256 ≈ 21.6 kHz
占空比CCAP1L / 256 = duty% × 256 / 10050% → CCAP1L = 128

本程序 CMOD = 0x02 → CPS=001 → SYSclk/2，于是 fPCA = 5.5296 MHz，fPWM = 5.5296M ÷ 256 ≈ 21.6 kHz，与注释、OLED 显示三者完全一致。寄存器值决定了频率，显示必须跟它对齐——这也是第 5 节对照手册验值要强调的。

（二）易错点（雷区）

🚧 雷区 1：把 CMOD 的 CPS 位猜错位置。STC15 的 CPS 在 B3~B1、ECF 在 B0（不是 Philips 经典的 B6~B4 / B3），务必查手册 SFR 表。

🚧 雷区 2：以为改占空比要进主循环不停写。8 位 PWM 只要写一次 CCAP1L 就持续生效，硬件自动循环。

🚧 雷区 3：CCAP1H 和 CCAP1L 不一致导致占空比抖动。改占空比时两个都写同一个值。

🚧 雷区 4：PWM 引脚忘了配推挽，方波边沿钝、电机啸叫。

🚧 雷区 5：启动电机前没先松闸（BRAKE=1），刹车锁死转不动。

（三）练一练

  • 若想要占空比 75%，CCAP1L 应写多少？把公式算一遍。
  • 若把 CMOD 改成 0x04（CPS=010 = 定时器0溢出），频率由什么决定？这给我们留下了哪种调速思路？
  • 把 Motor_SetSpeed(50) 改成 Motor_SetSpeed(0) 再启动，电机会怎样？结合"CCAP1L=0→恒高→不驱动"解释。

8下一节预告：按键配置占空比与启停方向

本讲我们把 PWM 这个"发动机"点着了，但它还只能在上电时固定 50% 转、且无法改变方向。下一节，我们就把按键接进来，做一个真正"可交互"的调速台：

  • 占空比调节：用按键"加 / 减"实时改变电机占空比，速度随之变化，并把新数值显示在 OLED 上；
  • 启动 / 停止控制：用一个按键控制电机转还是停（对应 Motor_Forward / Coast 或 Brake）；
  • 方向控制：用另一个按键在正转 / 反转之间切换（对应 Motor_Forward / Reverse）；
  • 届时你会看到：有了本讲打好的"PWM 黑盒"，加交互只是改几个数字 + 读几个按键的事——这正是分层设计的好处。
