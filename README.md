# STC15 矩阵按键 + PWM 直流电机调速 + OLED 显示

基于 **STC15F2K60S2 / IAP15F2K61S2**（CT107D 平台，11.0592MHz）的单片机教学项目：
4×4 矩阵按键配置直流电机占空比 / 启停 / 方向，PCA 8 位 PWM 调速（21.6kHz），OLED 中文界面。

## 功能一览

- **双工作模式**：自动模式（按一次触发一次）/ 点动模式（按住动、松开停），A 键切换（仅停止时有效）
- **方向控制**：B 键正转·停止复用、C 键反转·停止复用，正反转互锁（须先停再换向）
- **占空比调节**：
  - `*` / `#` 微调 ±1（限幅 1~100，运行中实时生效）
  - 数字键 `0~9` 直设两位数占空比（移位拼接滚动窗口，第三行最右侧预览）
  - `D` 键确认生效（`buf>0` 才写入，确认后缓冲自清零）
- **OLED 中文界面**：模式 / 占空比 / 状态 / 输入预览 四行显示，脏检查局部刷新防闪烁

## 键位分配

| 7 | 8 | 9 | **A**=模式切换 |
|---|---|---|---|
| 4 | 5 | 6 | **B**=正转·停止 |
| 1 | 2 | 3 | **C**=反转·停止 |
| * | 0 | # | **D**=确认占空比 |

## 硬件连接（实测为准）

| 模块 | 引脚 |
|---|---|
| 矩阵按键 | 行 ROW1~4 = P3.0~P3.3（输出），列 COL1~4 = P4.4 / P4.2 / P3.5 / P3.4（输入），**J5 跳线拨到矩阵按键侧** |
| 电机驱动 | PWM = P1.0（PCA 模块1，推挽），DIR = P0.4，BRAKE = P4.7 |
| OLED (I2C) | SCL = P0.7，SDA = P0.6 |

## 设计要点

- **一个模块两种读法**：`MatrixKey_Scan()`（边沿事件 + 显式消抖）用于自动模式；`MatrixKey_Read()`（电平状态，靠主循环 10ms 节拍隐式消抖）用于点动模式
- **两段式主循环**：公共段（A/*/​#/0~9/D，两模式逻辑相同写一遍）+ 模式段（B/C 按 mode 路由）
- **参数输入框架**：缓冲 + 预览 + 确认 + 自清零（`buf>0` 值本身即状态，无需额外标志位）
- **PCA 三模块可移植**：`motor.h` 一行 `#define MOTOR_PCA_MOD` 切换模块 0/1/2，switch 封装解决 C51 sfr 不能取地址的问题
