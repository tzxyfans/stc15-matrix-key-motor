一 IO 引脚图与各端口功能介绍

STC15F2K60S2 采用 LQFP44 封装，共有 44 个引脚。其中 8 根电源/复位专用引脚（P5.4、Vcc、Gnd 等），其余 36 根分布在 P0~P5 六个端口上，可作为通用 IO 或第二功能使用。

六大端口一览

下面用一张表把每个端口的"地址、引脚数、复用功能大类"整理好，方便快速查阅：

端口 引脚数 主要复用功能 典型用途
P0 8 AD0~AD7（地址/数据总线） 外扩存储器 / 8088 总线 / 通用 IO
P1 8 ADC0~7、CCP、SPI、串口 3 ADC 模拟采集、PWM、SPI 通信
P2 8 A8~A15（地址高 8 位） 外扩存储器高位地址 / 通用 IO
P3 8 UART1、外部中断、计数器、SPI_2、PCA_2 串口通信、外部中断、定时器输入
P4 7（部分封装） SPI_3、PCA_3、ALE、串口 2 等 扩展外设、片外总线
P5 1~3（LQFP44 仅 P5.5） 部分型号用作 RST、晶体等 特殊功能 / 保留

各端口详细功能

🔴 P0 口
8 位双向 IO · 地址/数据复用总线
P0.0 ~ P0.7 → AD0 ~ AD7
• 外扩总线时：分时复用低 8 位地址与 8 位数据
• 用作通用 IO 时：与 P1/P2/P3 类似，须配置模式
• 注意：开漏结构，用作输入时需外接上拉电阻
🟠 P1 口
8 位双向 IO · ADC + CCP + SPI + 串口 3
P1.0/P1.1 → ADC0/1, CCP1/0
P1.2~P1.5 → ADC2~5, SPI (SS/MOSI/MISO/SCLK)
P1.6/P1.7 → ADC6/7, 串口 3 (RxD_3/TxD_3)
🟡 P2 口
8 位双向 IO · 地址高 8 位
P2.0~P2.7 → A8 ~ A15
• 外扩存储器时输出高 8 位地址
• 用作通用 IO 时与普通端口无异
• 复用：SPI_2、PCA_3（P2.4~P2.7）
🟢 P3 口
8 位双向 IO · "明星端口"，功能最丰富
P3.0/P3.1 → 串口 1 (RxD/TxD)
P3.2/P3.3 → INT1/INT0
P3.4/P3.5 → T0/T1
P3.6/P3.7 → 串口 2、PCA_2、SPI_2
🔵 P4 口
辅助扩展口 · LQFP44 含 P4.0~P4.6
P4.0~P4.3 → SPI_3 / PCA_3
P4.4 → ARD（SPI 主模式"自动读"）
P4.5 → ALE
P4.6 → 串口 2 (RxD_2)
🟣 P5 口
LQFP44 仅有 P5.5，其他封装可能更少
P5.5 → 普通 IO / 部分型号作第二功能
LQFP48 / QFN48 等封装会引出 P5.0~P5.4 与 RST、XTAL 信号
使用前请查阅具体封装的 datasheet

二 IO 端口的四种工作模式

STC15 系列单片机每个 IO 口都可通过 PxM0 和 PxM1 两个寄存器（共 4 位，每位对应一个引脚）独立配置为四种工作模式之一。

PxM1 PxM0 模式名称 输出特性 典型应用
0 0 准双向口（传统 8051 模式） 弱上拉；输出低电平能力强，输出高电平靠弱上拉 推荐 默认模式，兼容 8051；按键输入、LED 低电平点亮、UART 等
0 1 推挽输出（强输出） 强上拉 + 强下拉，可输出 ±20mA 电流 推荐 LED 高电平点亮、蜂鸣器、DS18B20 单总线、I2C 模拟、驱动 MOS 管
1 0 高阻输入（仅输入） 既不上拉也不下拉，引脚呈高阻态 一般 ADC 模拟输入、外接上拉/下拉的按键、外部总线
1 1 开漏输出（类似 P0） 仅能拉低，需外接上拉电阻才能输出高电平 特殊 I2C 总线（SDA/SCL）、电平转换、线与逻辑

四种模式图解与配置示例

①

准双向口

P1M1 = 0x00; P1M0 = 0x00;

默认上电模式。读引脚前必须先写 1。可类比为"内部有 1 个超大电阻上拉 + 1 个强下拉管"。

②

推挽输出

P1M1 = 0x00; P1M0 = 0xFF;

高低电平均有强驱动能力，可直接点亮 LED 高电平、驱动蜂鸣器。无需外接上拉电阻。

③

高阻输入

P1M1 = 0xFF; P1M0 = 0x00;

引脚对外电路几乎无影响。用于 ADC 输入或与外部器件"线与"，避免干扰被测信号。

④

开漏输出

P1M1 = 0xFF; P1M0 = 0xFF;

只能拉低。高电平靠外部上拉电阻实现。多用于 I2C 总线、电平匹配场合。

📌 小贴士 · 寄存器对照：
P0 对应 P0M1 / P0M0，P1 对应 P1M1 / P1M0，依此类推。模式寄存器位于 SFR 区，上电默认全 0，即全部为准双向口。

使用建议（按场景选模式）

应用场景 推荐模式 原因
点亮 LED（低电平有效）准双向口默认即可，灌电流能力强
点亮 LED（高电平有效）推挽输出强上拉可直接驱动
按键输入准双向口传统用法，配合外部上拉或下拉
模拟量采集（ADC）高阻输入避免内部上拉干扰测量精度
I2C 总线（SDA/SCL）开漏输出配合外部上拉实现"线与"
DS18B20 单总线推挽输出强驱动确保时序波形陡峭
SPI 通信（MOSI/SCK）推挽输出保证高速翻转时的波形完整

三 IO 端口的第二功能介绍

所谓"第二功能"，是指引脚除了作普通 IO 之外的复用功能（如 ADC、SPI、UART、PWM 等）。开启第二功能后，对应引脚就由内部外设接管，IO 控制权交给外设寄存器。

（一）P0 口 — 地址/数据复用总线

📍 P0 第二功能一览
AD0 ~ AD7外部总线模式下的低 8 位地址 / 数据复用口。由 BUS_SPEED 等寄存器决定是否使能。
💡 当使用片外存储器（如并行 SRAM、8088 总线扩展）时，P0 自动作为地址/数据总线；否则 P0 完全可作普通 IO 使用。

（二）P1 口 — ADC + CCP + SPI + 串口 3

📍 P1 第二功能一览
引脚第二功能说明

P1.2ADC2 / SS / ECI_2ADC 通道 2；SPI 主模式"从机选择"；PCA 外部计数输入
P1.3ADC3 / MOSIADC 通道 3；SPI 主出从入

四 IO 端口的默认信号状态

单片机上电复位后，所有 IO 口都进入一个"安全初始态"。理解默认状态，才能在系统上电时避免误触发。

（一）上电复位后的默认状态

⚡ 默认模式：全部为准双向口
  • 所有端口 PxM1 = 0x00，PxM0 = 0x00 → 准双向口（弱上拉）
  • 所有端口 输出锁存器 = 1，即引脚默认输出 高电平
  • 可作为输入使用（读引脚前已写 1，符合准双向口用法）

（二）默认状态对照表

项目 默认状态 备注
端口工作模式准双向口（PxM1=0, PxM0=0）上电后所有端口统一
端口数据寄存器（P0~P5）1111_1111默认输出高电平
引脚电平高电平（弱上拉）驱动能力约 200μA
数字输入功能可用读引脚前先写 1（准双向口特性）
ADC 输入未开启需配置 P1ASF + ADC_CONTR
第二功能关闭需通过相应 SFR 寄存器开启
看门狗（WDT）关闭（复位后未启用）需软件设置 WDT_CONTR
RST 引脚（P3.4 复用）复位输入（仅在上电瞬间）复位完成后可作为普通 IO

（三）几个特殊的默认状态

🔧 P3.0 / P3.1 — 串口 1 的隐性高电平
  • 上电后 P3.0、P3.1 处于准双向口，且输出 1（高电平），符合 UART 空闲状态要求
  • 若使用外部电路上拉，确保上拉电压与 Vcc 一致，避免灌电流
🔧 P0 口 — 上拉电阻需外接
  • P0 在用作普通 IO 输入时，内部没有上拉电阻（与 P1/P2/P3 不同）
  • 上电后默认输出锁存器 = 1，但因无上拉，引脚呈高阻态
  • 建议：P0 用作输入时必须外接 4.7kΩ~10kΩ 上拉电阻
🔧 P3.4 / RST — 复位脚的双重身份
  • 上电瞬间：P3.4 作为复位输入，外部低电平可使单片机复位
  • 复位完成后：P3.4 可作为普通 IO 或 T0 / T1CLKO 等第二功能
  • 若不使用外部复位，外部复位引脚可通过 10kΩ 电阻上拉到 Vcc，再用作 IO

（四）推荐初始化代码模板

系统上电后，先按项目需求重新配置 IO，再操作外设，避免默认状态与硬件冲突。

// 1. LED 接在 P1.0~P1.3（高电平点亮），配置为推挽输出
P1M1 = 0x00;   // 清 0
P1M0 = 0x0F;   // P1.0~P1.3 推挽输出，其余保持准双向口
P1   = 0x00;   // 初始点亮

// 2. 按键接在 P3.2/P3.3（外部下拉到 GND，按下低电平）
P3M1 = 0x00;
P3M0 = 0x00;   // 保持准双向口（内部弱上拉）
P3   = 0x0C;   // P3.2/P3.3 写 1，准备读引脚

// 3. P1.4 用作 ADC 输入，必须配置为高阻输入
P1M1 = (P1M1 & ~0x10) | 0x10;   // P1M1.4 = 1
P1M0 = (P1M0 & ~0x10);           // P1M0.4 = 0 → 高阻输入
P1ASF = 0x10;                    // 开启 P1.4 的 ADC 功能
📚 学习小结：
① 六大端口（P0~P5）共 36+ 个 IO；② 每位独立配 4 种模式，靠 PxM1 / PxM0；
③ 第二功能由 SFR 寄存器开启，注意不要与普通 IO 占用冲突；
④ 默认全部准双向口、输出高电平；P0 用作输入需外接上拉。
